# IntelliJ Platform Extension - Twirl Templates Support

> This plugin is currently a work-in-progress (WIP)
> and there is currently no set or expected date for
> time of release.

This is a free, open-source plugin designed for bringing
support for Play framework's Twirl templates into the popular
IntelliJ editors.

This is a free and open-source extension, and it is **not**
officially associated with JetBrains, Scala, or Play framework.
